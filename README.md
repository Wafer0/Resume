# Resumes

Specialized resume versions for different engineering roles, plus comprehensive technical audit.

## Resume Directories

- `asic_fpga/` - ASIC/FPGA/Chip Design focused resume
- `courtyards_ra/` - Resident Assistant focused resume
- `ee/` - Electrical Engineering focused resume
- `hardware/` - Hardware Engineering focused resume
- `swe/` - Software Engineering focused resume
- `vlsi/` - VLSI Design focused resume
- `old_resumes/` - Original resume template and versions

## Files

- `comprehensive_audit.md` - Master technical audit with coursework analysis, project deep-dives, and skills matrix
- `compile_resumes.sh` - Automated script to compile all resume PDFs

## Usage

Run `./compile_resumes.sh` to compile all resume versions.

Compiled PDFs are placed in their respective directories with names `Andreas_Tzitzikas_Resume_[letter].pdf` where:
- `a` = ASIC/FPGA resume → `asic_fpga/`
- `b` = Electrical Engineering resume → `ee/`
- `c` = Hardware Engineering resume → `hardware/`
- `d` = Software Engineering resume → `swe/`
- `e` = VLSI Design resume → `vlsi/`
- `ra` = Resident Assistant resume → `courtyards_ra/`
